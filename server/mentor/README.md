# Парсер материалов ментора

`markdown.ts` и `markdown-validator.ts` скопированы без изменения функций из
https://github.com/a-kalki/u7-school/tree/d39efe27d5e29702acd58de372ac1c1f105a83db/packages/core/src/shared

Бот использует `safeConvert(content)` для текстовых шагов и `mdCodeBlock(code)`
для шагов кода. Его зависимость — markdown-to-telegram 0.0.7, версия зафиксирована
в нашем package-lock.json. Адаптер server/telegram-format.ts декодирует полученный
MarkdownV2 в текст и сущности, React выводит их без вставки HTML. Исходные content
и code в data/catalog.json остаются неизменными.

При sync:content сравниваются исходники парсера с той же ревизией, что и материалы.
Если парсер или зависимость изменились, синхронизация прекращается до проверки
и обновления этих файлов. Скачанный код автоматически не исполняется.

Незакрытая тройная ограда кода отклоняется до конвертации: текущий upstream
preprocessor может зациклиться на ней. Исходный Markdown не исправляется.

Сравнение renderingComparison проверяет текст тела текущего сообщения бота,
не включая заголовок прогресса. Различие может означать старый снапшот курса в
потоке бота; это не меняет исходный материал и не подтверждает выполнение.
Внешний вид шрифтов и переносов браузера/Telegram не обещает пиксельного совпадения.
